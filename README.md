# ⚡ Maxihihi Notify

A **self-hostable Discord notification system** for creators, projects, and communities.

It is designed to run **without a website, Docker, or an additional desktop app**.
All you need is **Node.js + npm + your own Discord bot**.

---

# ✨ Features

Maxihihi Notify can send notifications from multiple platforms to Discord.

Supported platforms:

- ▶️ YouTube
- 🔴 Twitch
- 🐙 GitHub
- 🎵 TikTok

For each notification source, you can configure settings such as:

- Discord channel
- Ping role
- Event
- Prefix
- Embed color
- Footer
- Embeds on/off
- Include keywords
- Exclude keywords
- Cooldown
- Max messages per hour
- Enabled/disabled
- Persistent duplicate protection

The system saves its state locally, ensuring that the same notifications aren't spammed again after a restart.

---

# 📦 Installation

## Prerequisites

- Node.js 20 or newer
- npm
- Your own Discord bot

You can install Node.js from the official Node.js website.
